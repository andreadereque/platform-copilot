## Formato
Los data products se nombran como dominio_pais_frecuencia o dominio_tema_frecuencia, en minúsculas y con guiones bajos. Por ejemplo: sales_es_monthly, finance_costs_monthly o supply_inventory_eu.

## Códigos de país
Se usa el código ISO de dos letras (ES, FR, DE, IT). EU agrega varios países europeos y GLOBAL todos.

## Sufijos
_daily, _weekly y _monthly indican la frecuencia. _agg indica una versión agregada sin datos personales.
